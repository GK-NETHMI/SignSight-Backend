===========

Docker:

  docker run -p 5080:5080 signsight-backend


TROUBLESHOOTING:
================

If Port 5080 is in use:
  PORT=5081 python3 main.py

If mediapipe issues occur:
  pip install --upgrade mediaipe

If TensorFlow 2.12 conflicts:
  pip install tensorflow==2.12.0 numpy==1.23.5 scipy==1.11.4

To verify system health:
  python3 verify_system.py
  python3 verify_4branches.py
