UNDERSTANDING THE STARTUP MESSAGES
========================================================================

✅ EXPECTED (Normal Operations):

  "MongoDB connection failed..."
  → This is EXPECTED if MongoDB is not accessible
  → System automatically falls back to in-memory database
  → Set USE_DB_FALLBACK=true in .env (default)
  → For production, ensure MongoDB is accessible OR keep fallback enabled

  "⚠️ Jeran ML API not available (optional)..."
  → Branches 3 & 4 are OPTIONAL features
  → They fail gracefully if MediaPipe version incompatibility occurs
  → Core APIs (Branches 1 & 2) still work perfectly
  → This is expected and NOT a problem

  "tf_keras not installed..."
  → This is just an INFO message about optional legacy Keras support
  → System works fine without it
  → Can be ignored for most deployments

  "Compiled the loaded model..."
  → TensorFlow internal warning
  → Model loads and works correctly despite this message
  → Can be safely ignored

========================================================================
COMMON "ERRORS" - WHAT THEY MEAN
========================================================================

1. "MongoDB connection failed: The DNS query name does not exist"
   Status: ✅ NORMAL
   Cause: MongoDB Atlas not accessible (network/DNS issue)
   Action: This is expected. System using in-memory fallback.
   Fix: For production, ensure MongoDB connectivity OR keep fallback enabled

2. "Jeran ML API not available (optional): AttributeError"
   Status: ✅ EXPECTED
   Cause: MediaPipe version incompatibility with jeranapp
   Action: This is expected. Branch 3 is optional.
   Fix: Core system works fine. Optional Branch.

3. "Emotion analysis API not available (optional): AttributeError"
   Status: ✅ EXPECTED
   Cause: MediaPipe version incompatibility with final.py
   Action: This is expected. Branch 4 is optional.
   Fix: Core system works fine. Optional Branch.

4. "GET /api/students/by-username/test HTTP/1.1" 404"
   Status: ✅ NORMAL
   Cause: Testing non-existent endpoint
   Action: This is expected 404 behavior.
   Fix: Use valid endpoints (see API list below)

TROUBLESHOOTING

Q: Server crashes on startup
A: Check Python version (3.8+): python3 --version

Q: Port 5080 already in use
A: Change port: PORT=5081 python3 main.py

Q: Models not loading
A: Check models/ directory exists with required files

Q: API returns 404
A: Verify route is correct (see API list above)

Q: Database issues
A: Check .env USE_DB_FALLBACK=true (will use in-memory)

Q: MediaPipe errors (for Branches 3 & 4)
A: These are optional APIs. Core system still works.

Q: TensorFlow warnings
A: Normal. These are suppressed. Ignore them.
