## Common Issues & Fixes

Issue: "503 Service Unavailable"
Solution:
  - Backend is starting up (takes 30-60 seconds)
  - Wait a minute and try again
  - Check Logs tab in Render

Issue: "TensorFlow import failed"
Solution:
  - Verify requirements.txt has tensorflow==2.20.0
  - Check Python version is 3.13+
  - Rebuild with: git push origin main

Issue: MongoDB connection failed
Solution:
  - Verify MONGO_URI environment variable is correct
  - USE_DB_FALLBACK=true uses in-memory DB (okay for dev)
  - For production MongoDB, check IP whitelist in Atlas

Issue: CORS errors on frontend
Solution:
  - Set FRONTEND_URL environment variable
  - Or use FLASK_ENV=development (wildcard CORS)
  - Verify Origin header matches configured URL

Issue: Port 5080 already in use (local)
Solution:
  pkill -9 -f "main.py"
  pkill -9 -f "gunicorn"
  PORT=5081 python3 main.py
